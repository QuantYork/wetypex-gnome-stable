# GNOME 顶栏录音状态设计

- 位置：主屏 GNOME 顶栏左侧图标组的最右侧，文字向右延伸，不在右侧系统图标组内分配空间；不改动上游扩展文件。
- 空闲时隐藏；准备时显示“正在准备录音”；录音期间持续显示绿色麦克风、文字和真实时长。
- 停止后显示蓝色整理状态；提前按回车显示“定稿后发送”；完成 1.5 秒后隐藏。
- 状态异常使用橙色；如果状态已失联但录音进程仍存活，持续提示“录音仍在进行”，不隐藏错误。
- 不创建正文上方的浮动窗口，不抢焦点，不可点击，不改变候选框和快捷键。
- Python 服务复用 `voice_status.py` 校验 PID 与启动时间。扩展通过异步 D-Bus `Poll` 每 250 毫秒读取简短状态；录音和识别逻辑保持原样。
- 只有实际消费者轮询时才更新就绪心跳。没有顶栏消费者时保留普通通知回退。
- 启用持久用户服务及 GNOME 扩展开关，下次图形登录继续可用；初次发现新本地扩展需要重新登录。
- 已通过隔离 D-Bus 服务、GJS 显示逻辑和语法测试；实际顶栏渲染、相邻位置、全屏及多显示器场景尚待用户确认。

参考 GNOME 官方扩展开发文档的 [顶栏指示器示例](https://gjs.guide/extensions/development/creating.html)。安装及恢复见[语音输入说明](voice-input.md)。
