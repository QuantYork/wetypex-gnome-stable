# 改动与验证

## 发布内容

| 文件/组件 | 作用 |
|---|---|
| `src/prekey-anchor.cpp` | 首键前保存光标，仅候选 UI 读取保存位置 |
| `src/window-anchor.c` | 保留原 Classic UI 窗口可见期固定兼容 |
| `scripts/backend-json-compat.py` | 保留已验证的后端 JSON 字符兼容 |
| `scripts/wetypex-gnome-stable` | 稳定启动路径、版本检查、默认关闭坐标诊断 |
| `scripts/install.py` | 原子安装、备份、持久用户服务、避免重复 XDG 自启动 |
| `scripts/uninstall.py` | 停用服务、按清单恢复、保留用户后续修改 |
| `tests/` | 两条 UI 路径的隔离验证、安装卸载恢复、可选 X11 测试 |

## 需要用户另外安装的组件

Fcitx 5、WeTypeX 及其输入核心，GNOME Input Method Panel 扩展。本项目不附带这些上游二进制或资源。扩展 v92 的官方站下载包 SHA256 为 `7a12cddb91964e3aaf207f794ede485f581567fce5bbae0370399159ccddc31a`，可从官方扩展页面获取兼容版本。

## 本机实际反馈

- 首键前保存位置使 ChatGPT、微信、Edge 的候选起点一致且不再跟随拼音移动。
- 只放行 GNOME 共用上下文没有解决原生应用左上偏移。
- 启用 Kimpanel 并接入首键前保存后，用户确认终端、应用中心、文本编辑器、Firefox 等已测应用正常。
- 候选框改用 GNOME 面板样式，微信风格暂未迁移，用户已接受。

这些是人工反馈，不能替代所有应用的回归测试。重新登录验证需要用户在完成当前会话后实际进行；不能为了验证自动启动而擅自注销桌面。

## 未触碰的数据

安装器不修改用户词库、微信账户、配对身份、聊天内容、WeTypeX 配置 JSON、浏览器配置和其他聊天任务的源码目录。仓库不包含真实诊断坐标日志、截图、用户文件、SSH 私钥或微信核心。

## 打包时修复的构建问题

重新编译旧窗口层时，链接器的 `--as-needed` 可能移除其 `libxcb.so.1` 动态依赖。桌面 UI 使用局部加载方式时，`RTLD_NEXT` 查找 XCB 函数可能失败，导致启动崩溃。构建脚本现在显式保留 XCB 依赖，并新增 `RTLD_LOCAL` 模拟加载回归测试。修复后的持久服务已经在本机启动验证。
